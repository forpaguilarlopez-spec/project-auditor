# Project Auditor

CLI local y extensible para auditar proyectos software.

## Objetivo

Project Auditor analiza proyectos en local y genera informes Markdown con información sobre:

- tecnologías detectadas;
- documentación básica;
- estructura del proyecto;
- scripts de calidad;
- dependencias relevantes;
- configuración de herramientas.

## Uso en desarrollo

npm install

npm run dev analyze /ruta/al/proyecto

## Scripts

npm run format

npm run typecheck

## Estado

Proyecto en desarrollo como herramienta de aprendizaje y portfolio.
